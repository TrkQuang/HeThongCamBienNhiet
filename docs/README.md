# docs/ - Tài liệu

## Mục đích

Tài liệu kiến trúc, API, hướng dẫn người dùng.

## Chứa gì

- architecture.md
- api_spec.md
- user_guide.md
- troubleshooting.md

## Danh sách file

- architecture.md: Mô tả kiến trúc tổng thể.
- api_spec.md: Đặc tả API và payload.
- user_guide.md: Hướng dẫn sử dụng hệ thống.
- troubleshooting.md: Xử lý lỗi thường gặp.

## Ví dụ sử dụng

Đọc `api_spec.md` để thống nhất format payload.
