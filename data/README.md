# data/ - Dữ liệu cục bộ

## Mục đích

Lưu file DB và dữ liệu phát sinh khi chạy.

## Chứa gì

- README.md (mô tả thư mục)
- File DB sẽ được tạo khi chạy (ví dụ: temperature.db)

## Danh sách file

- README.md (doc): Mô tả mục đích thư mục dữ liệu.
- temperature.db (artifact/db): File SQLite tạo khi chạy (ví dụ).

## Ví dụ sử dụng

DB sẽ xuất hiện tại thư mục này sau khi API ghi dữ liệu.
